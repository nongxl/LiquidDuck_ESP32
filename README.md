# 🦆 LiquidDuck — ESP32-S3 终极物理沙盒

本项目最初为 M5Cardputer 上的小黄鸭液体模拟，现已深度重构升级为**三合一终极数字物理沙盒**！支持运行在具有更高算力的 **M5StickS3** 和 **M5Cardputer** 上，包含极致水流体验的 FLIP 引擎与复古碰碰球体验的 PBD 引擎，并完美融合了 `FloatingBottle` 数字海洋瓶。

---

## 🌟 核心亮点

- **双引擎 & 三模式热切换**：
  - **🦆 鸭子水花模式 (FLIP, 横屏)**：通过引入不可压缩性流体动力学引擎 (FLIP)，实现高度拟真的水花飞溅、波浪推挤和小黄鸭自然上浮效果。
  - **🔵 复古颗粒模式 (PBD, 横屏)**：保留了经典的基于位置动力学 (PBD) 算法，高达 180 颗独立刚体球，极低粘性、极高弹性，可体验如沙子般顺滑的重力交互。（注：可在 `config.h` 中开关该模式）
  - **🌊 数字海洋瓶 (Bottle, 竖屏)**：引入高密度（27x48）的深海蓝渐变体渲染管线。切入此模式时系统将瞬间翻转为竖屏映射，您可以像握持真正的水瓶一样把玩流体！
- **触觉与视觉双重反馈**：
  - 屏幕引入多层霓虹晶体高亮渲染。
  - 底层接入 Haptic 震动引擎，根据粒子撞墙的能量实时计算 PWM，带来清晰的段落感与解压撞击感。
- **动态显存管控**：在 ESP32-S3 的 8MB PSRAM 加持下，后台可同时承载两套独立的物理空间解算而不掉帧，全程锁定 **60FPS**！

## 🛠 硬件需求

| 组件 | 说明 |
|------|------|
| **M5StickS3 / M5Cardputer** | ESP32-S3，240×135 屏幕，内置 IMU 陀螺仪 |
| **Hat Vibrator (马达模块)** | 连接至 `GPIO 0` 用于高频物理震动反馈 (可选) |

无需 SD 卡，无需网络，开机即玩。

## 🎮 操作说明

| 硬件操作 | 效果说明 |
|------|------|
| **倾斜设备** | 重力映射将根据横竖屏模式自动匹配，流体/粒子实时流动。 |
| **按下 BtnB** | 🔄 **一键切换世界法则**：在 `FLIP 鸭子水花` ↔ (`PBD 颗粒碰撞`) ↔ `Bottle 竖屏海洋` 之间无缝切换。 |
| **按下 BtnA / Enter** | 💥 **爆炸交互**：在鸭子模式和颗粒模式下，向小黄鸭注入巨大反推力能量，制造瞬间的水花四溅。 |

## ⚙️ 可调参数 (`src/config.h`)

所有的物理特性已经全部模块化并抽离至 `config.h` 中，您可以根据口味自由调优：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `FLIP_RATIO` | 0.90f | [FLIP] 混合系数。越高越保留流速动能，越低越粘稠平滑。 |
| `FLIP_PRESSURE_ITERS` | 12 | [FLIP] 压力求解迭代数。控制水的“不可压缩性”与硬件开销平衡。 |
| `PBD_DAMPING` | 0.995f | [PBD] 速度阻尼。越接近 1.0 运动越滑溜、响应越快。 |
| `PBD_STIFFNESS`| 0.5f | [PBD] 碰撞刚性。控制粒子间碰撞挤压时的弹开力度。 |
| `ENABLE_PBD_MODE`| false | 是否在 BtnB 按键循环中暴露 PBD 颗粒模式。 |
| `FLUID_GRAVITY_BOTTLE` | 16.0f | [Bottle] 竖屏模式下的流体拉力响应速度。 |
| `IMU_DEADZONE` | 0.16f | IMU 死区过滤，用于消除设备放置桌面静止时的屏幕流体“沸腾”抖动。 |

## 🏗 技术架构

- **分离式逻辑树**：渲染 (`renderFrame`) 与 物理 (`physicsStep`) 被严密拆分。每帧系统只执行活跃模式的函数，被切换到后台的物理引擎进入挂起状态，不消耗 CPU 周期。
- **高频子步长 (Sub-stepping)**：不论是 PBD 还是 FLIP，引擎都使用高频物理步长分割（如 `SUB_STEPS=4` 或 `0.5*dt`）来避免高速运动下的穿模问题。
- **动态坐标系翻转**：切换至 `MODE_BOTTLE` 时，直接控制底层 `setRotation(0)` 与重建 Canvas Sprite，并将重力向量重新映射为 `gx = -ay; gy = -ax;`。
