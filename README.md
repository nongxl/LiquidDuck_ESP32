# 🦆 LiquidDuck — ESP32-S3 伪流体粒子系统

> M5Cardputer 上的小黄鸭液体模拟

---

## 效果演示

- **约 360 个蓝色粒子**在屏幕内流动，模拟液体行为
- **倾斜设备**即可改变重力方向，粒子实时响应
- **小黄鸭**漂浮在粒子上方（低密度模拟）
- **碰撞音效**：粒子强烈碰撞时发出 tick 声
- **≥30 FPS** 实时物理 + 渲染

---

## 硬件需求

| 组件 | 说明 |
|------|------|
| **M5Stack Cardputer** | ESP32-S3，240×135 屏幕，内置 IMU + 扬声器 |

无需 SD 卡，无需网络。

---

## 编译 & 烧录

```bash
# 安装 PlatformIO 后执行
pio run -e m5cardputer -t upload
```

## 操作说明

| 操作 | 效果 |
|------|------|
| **倾斜设备** | 改变重力方向，粒子随之流动 |
| **按 Enter 键** | 重置粒子位置 |

## 可调参数（src/main.cpp）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `NUM_PARTICLES` | 360 | 粒子数量 |
| `PARTICLE_RADIUS` | 2.5 | 粒子半径 (px) |
| `DUCK_RADIUS` | 10 | 鸭子半径 (px) |
| `GRAVITY_STRENGTH` | 280 | 重力加速度 (px/s²) |
| `DAMPING` | 0.985 | 速度阻尼 (每帧) |
| `BOUNCE` | 0.72 | 边界弹性系数 |
| `IMU_LPF_ALPHA` | 0.12 | IMU 低通滤波强度 |
| `SOUND_THRESHOLD` | 3.0 | 触发音效的最小碰撞冲量 |

## 技术架构

### 物理引擎
- **固定时间步长** `dt = 1/60s`
- **空间网格（Grid）** 划分碰撞检测，避免 O(n²)，每粒子仅检查 9 邻格
- **短程排斥**：粒子重叠时施加位置修正 + 轻微速度分离
- **鸭子低密度**：重力缩放 `0.35×`，自然上浮；跟随邻近粒子速度场平滑漂移

### 渲染
- **M5Canvas 双缓冲 Sprite**，每帧全量绘制后 `pushSprite` 到屏幕
- 速度越快粒子越亮（动态高光）
- 右上角实时 FPS 显示

### IMU 重力映射
- 读取加速度计 `ax`/`ay`，经低通滤波后映射为屏幕坐标系重力向量
- 无 IMU 时回退为默认向下重力
